# Breast-Cancer-Diagnosis-using-Logistic-regression
A binary classification problem  to predict whether a tumor is malignant (cancerous) or benign (non-cancerous) based on medical features.
# Final Outcome
Our model achieved an overall accuracy of 97%. The precision and recall for benign (class 0) were 97% and 99%, respectively.From the confusion matrix the model identified 70(True positive) benign while 1(False positive) was incorrectly classified as malignant.For malignant (class 1), the precision and recall were 98% and 95%, respectively.The model correctly predicted 41(True negative) malignant cases, while 2(false negatives) cases were incorrectly classified as benign.
